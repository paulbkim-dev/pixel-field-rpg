# Pixel Field RPG

A pixel-art action RPG in a single HTML file. Roam the field, hunt monsters, level up, and take down the King Slime.

**Play:** https://paulbkim-dev.github.io/pixel-field-rpg/

Controls: WASD/arrows move · J/Space attack · K spin slash · L/Shift dash · Q potion · E shop (near the merchant) · M mute
